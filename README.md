# EduGenie

EduGenie is a Google Gemini-powered Learning Assistant that helps students understand concepts, generate summaries, and receive educational explanations instantly.

## Features

- AI-powered learning support
- Concept explanations
- Study assistance
- User-friendly interface

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML
- CSS

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open:

http://127.0.0.1:5000
